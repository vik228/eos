# Personal Knowledge Base Pending Updates

This is the top-level pending-update router for personal knowledge. Agents should start here, then open the project-specific or area-specific pending file for the current task.

## Project Pending Queues

- EOS: [projects/eos/_pending-kb-updates.md](projects/eos/_pending-kb-updates.md) - proposed durable updates for EOS personal collaboration context.

When a project needs pending knowledge updates, add:

- Pending updates: `projects/<project-name>/_pending-kb-updates.md`
- Project index: `projects/<project-name>/00-index.md`
- Summary: one sentence describing what proposals belong in that queue

## Area Pending Queues

No personal area pending queues are registered yet.

When an area needs pending knowledge updates, add:

- Pending updates: `areas/<area-name>/_pending-kb-updates.md`
- Area index: `areas/<area-name>/00-index.md`
- Summary: one sentence describing what proposals belong in that queue

## How Agents Should Use This

1. Start with this top-level pending index.
2. Pick the project-specific or area-specific pending queue that matches the task.
3. Review pending items before proposing new memory or KB updates.
4. Do not apply pending updates unless the user explicitly asks or approves the change.
